# MSPCA Companion App - Community Feedback & Issue Tracker

Welcome to the public feedback and issue tracker for the **MSPCA Companion (Unofficial)** mobile application.

This repository is dedicated to collecting community feedback, bug reports, feature suggestions, and inquiries regarding the companion app.

> **Disclaimer:** This project is an independent community initiative created by animal welfare advocates to help increase visibility for adoptable animals. It is **not** officially affiliated with, endorsed by, or operated by MSPCA-Angell.

---

## 🐾 How to Reach Out or Get Involved

### 🐛 Reporting a Bug
Found a problem or unexpected behavior in the mobile app?
- **[Open a Bug Report](../../issues/new?template=bug_report.md)**
- Please include your device model (iOS / Android / Web) and steps to reproduce.

### 💡 Feature Requests & Ideas
Have an idea for making the companion app better for adopters or shelters?
- **[Submit a Feature Request](../../issues/new?template=feature_request.md)**

### 🏥 Questions from MSPCA-Angell Staff or Representatives
If you represent MSPCA-Angell or a partner rescue organization and have questions, suggestions, or concerns:
- **[Open a General Inquiry](../../issues/new?template=general_inquiry.md)**
- We welcome collaboration, feedback, and data guidance to best serve adoptable animals.

---

## 🔒 Code & Service Notice
The source code for the backend data pipeline and visual search service is maintained in a private repository to ensure system stability and responsible use of resources. This repository is dedicated to public issue tracking, roadmap ideas, and community feedback.
